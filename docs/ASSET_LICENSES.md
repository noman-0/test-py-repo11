# Asset sources and licences

Every visual or audio asset used by the website and its 3D experience is listed here.

All replaceable paths are registered in [`src/experience/config/assetManifest.ts`](../src/experience/config/assetManifest.ts). To replace an asset, drop the new file at the same path; no application code needs to change.

## 1. Client brand assets (Excelsa Brand Identity Style Guide)

**Source:** `Excelsa.pdf`, the client's brand guide. See [BRAND_REFERENCE.md](BRAND_REFERENCE.md).

**Rights:** client-owned brand identity.

| Path | Derived from | How it was made |
|---|---|---|
| `public/brand/logo/excelsa-logo-official-cream.png` | PDF page 4 | Cropped at 300 dpi, background keyed out (official artwork, not redrawn) |
| `public/brand/logo/excelsa-logo-official-green.png` | PDF page 3 | Same process |
| `public/brand/logo-layers/*.png` (7 layers) | Official cream logo | Pixel masks of the official raster. Stacked together they reproduce it exactly (verified: max difference 0) |
| `public/brand/icons/*` (favicons, app icons) | Official logo | The logo's arch-window mark (arch, rays, drop) cropped and placed on #072B29 |
| `public/brand/og/excelsa-og.jpg` | Official logo | Unmodified logo centred on #072B29 |
| `brand-assets/excelsa-guide/**` | PDF pages 1–27 | Reference crops only. Mockups are **not** used as website imagery |

Generated by `scripts/extract-brand-assets.py` and `scripts/build-brand-web-assets.py`. Neither script overwrites existing files.

**Waiting on the client:** the original **vector** logo (Adobe Illustrator, SVG or PDF), and a commercial web licence for **Regista**.

## 4. Fonts

Playfair Display, Plus Jakarta Sans and IBM Plex Sans Arabic are the same families the site already loaded from Google Fonts. They're licensed under the SIL Open Font License 1.1 and are now self-hosted at build time via `next/font`.

## 5. Not used

- **Product mockup images from the brand guide.** They're used as references only, and some contain third-party stock elements.
- **The iced-latte photo** (PDF pages 23–24). It's mood reference only and is **not** presented as a menu product.
- **The review QR code** (PDF page 22). It isn't reproduced because no QR data was supplied; the official logo is shown instead.
